# TestShop

Backend REST API for a shop application built with Python, Django, and Django REST Framework.

## 🛠️ Technologies

* Python
* Django
* Django REST Framework
* SQLite
* Django ORM

## 📦 Project Structure

```text
TestShop/
├── TestShop/
├── api/
├── api.http
├── db.sqlite3
└── manage.py
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AbiwDev/TestShop.git
cd TestShop
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the virtual environment

Windows:

```bash
.venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install django djangorestframework
```

### 5. Apply migrations

```bash
python manage.py migrate
```

### 6. Run the development server

```bash
python manage.py runserver
```

The project will be available at:

`http://127.0.0.1:8000/`

This project was created to practice backend development, REST API development, and working with Django and Django REST Framework.
